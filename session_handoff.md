# Session Handoff

## Проект
Flask-приложение для сравнения табеля (Google Sheets) с данными СКУД (xlsx).
- Репо: https://github.com/AlexanderBrolin/comparer
- Ветка: `main`
- Запуск: `cd C:\Projects\comparer && venv\Scripts\activate && python run.py` → http://localhost:5000
- Логин: `admin` / `admin`

## Что было сделано в этой сессии

### Исправления логики
1. **Детектор смен** — исправлен баг: смена начинающаяся вечером и заканчивающаяся до полуночи (не переходящая на следующий день) ошибочно помечалась как Broken. Теперь Pass 2 ищет конец смены в том числе в тот же день.

2. **Цвет ячеек матрицы** — переработана логика на основе `excess = skud - tabell`:
   - Зелёный (OK): `0.9 < excess ≤ 1.1` (СКУД = Табель + 1ч перерыв ±10%)
   - Красный (нам должны): `excess ≤ 0.9`
   - Оранжевый (мы должны): `excess > 1.1`

3. **Тип смены из табеля** — значение с `(` (например `10(`) означает ночную смену. Теперь:
   - `sheets_reader.py`: парсит флаг `(`, заполняет `TabellEntry.daily_is_night`
   - `comparator.py`: СКУД-часы разделены на `skud_day_hours` / `skud_night_hours`, сравнение идёт строго по типу из табеля

4. **Новое расписание с 9 мая 2026** — добавлен Pass 1.5 в `shift_detector.py`:
   - Дневная смена: 15:00 → 01:00 следующего дня → `ShiftType.DAY`
   - Ночная смена: 01:00 → 11:00 → `ShiftType.NIGHT` (уже ловился Pass 3)
   - Константа `NEW_SCHEDULE_FROM = date(2026, 5, 9)` — Pass 1.5 применяется только с этой даты
   - До 9 мая старое расписание (ночная 17:00→04:00) работает без изменений

### Новые функции UI
5. **Колонки-итоги в матрице** — после колонки Position добавлены 4 сортируемые колонки:
   `Broken | N | Hours (SKUD) | Hours (Tabell)`
   - Broken и N подсвечены красным если > 0
   - Клик по заголовку — сортировка ▼/▲

6. **Period Totals** — блок над матрицей (две карточки: By Tabell / By SKUD):
   - Часы, дни, сотрудников за период

7. **Поиск по ID** — поле в правом верхнем углу матрицы, фильтрует строки в реальном времени

8. **Убраны блоки** Summary и Broken Shifts со страницы Dashboard (были избыточны)

## Архитектура (ключевые файлы)

| Файл | Роль |
|------|------|
| `app/services/shift_detector.py` | 5-pass алгоритм детектирования смен из пунчей СКУД |
| `app/services/sheets_reader.py` | Загрузка табеля из Google Sheets CSV, парсинг `(` флага |
| `app/services/comparator.py` | Сравнение СКУД vs табель, расчёт totals и period_totals |
| `app/models.py` | Датаклассы: `PunchRecord`, `Shift`, `TabellEntry`, `ShiftType` |
| `app/routes.py` | `/` (dashboard) + `/api/compare` + `/api/projects` |
| `app/static/js/app.js` | Весь фронтенд: загрузка файла, рендер матрицы, сортировка, поиск |
| `app/static/css/style.css` | Стили (темы: elegant, polati-light, polati-dark) |
| `app/templates/dashboard.html` | Единственная страница UI |
